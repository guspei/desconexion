# desconexión

Pantalla de inicio para Android para usar el teléfono solo para lo importante: bloquea apps y webs, limita minutos al día y silencia el resto.

## Instalar

Descarga `desconexion.apk` desde [Releases](https://github.com/guspei/desconexion/releases/latest), ábrelo en el teléfono y sigue la guía.

Si accesibilidad sale bloqueada: información de la app → ⋮ → permitir ajustes restringidos.

## Compilar

`./apk.sh` genera `desconexion.apk`. `./instalar.sh` además lo instala por adb y concede los permisos.
